# Inicio de Sesión

**Etapa del curso · Acceso al programa**

Una vez ingresadas las licencias válidas suministradas por tu proveedor, puedes acceder a Cabinet Report con las credenciales del usuario asignado.

## Paso a paso

1. Abre Cabinet Report y localiza la pantalla de inicio de sesión.
2. Escribe o selecciona en la lista el **nombre de usuario** asignado.
3. Introduce la **contraseña** correspondiente.
4. Haz clic en **Ingresar** o presiona **Enter**.

{% hint style="info" %}
**Licencias y acceso:** normalmente las licencias se ingresan una sola vez durante la configuración inicial. Solo será necesario cambiarlas si te asignan una nueva licencia. No compartas tu contraseña.
{% endhint %}
